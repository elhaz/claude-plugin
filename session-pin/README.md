# session-pin

세션 핀 — Claude Code 세션마다 **미결 질문·진행 중·끝남** 을 Obsidian 볼트 노트 하나에 모은다.
긴 대화에서 Claude 가 던진 질문이 답 없이 밀려 사라지는 것을 막고, 폰·PC 어디서나 볼트로 확인한다.

## 만든 배경

Claude Code 의 pinboard 기능(터미널 화면에 미결 질문·진행 상황을 고정해 보여 주는 mod)을 보고,
이를 **Claude 데스크톱 앱과 Obsidian 을 쓰는 환경에서도 비슷하게 쓰고 싶어** Claude 에게 요청해 만들었다.
pinboard 는 터미널 전용이고 세션이 끝나면 사라지지만, 이 플러그인은 같은 역할을 훅과 볼트 노트로 옮겨
데스크톱 앱·Remote Control(폰)·터미널 어디서 작업하든 Obsidian 에서 같은 보드를 보게 한다.

## 동작

| 훅 | 하는 일 |
|----|---------|
| `UserPromptSubmit` | 열린 항목과 노트 경로를 컨텍스트로 주입. 프롬프트가 `핀`(또는 `핀 보여줘`)이면 보드 전체를 보여 주게 하고, `핀 닫기` 면 이 세션 노트를 지운다. 대화가 멈춘 다른 세션 노트도 함께 정리한다 |
| `Stop` | 마지막 답변 끝 1200자에서 `?` 로 끝나는 문장을 「미결 질문」 에 추가. 뒤에 ` — 맥락`(같은 줄의 앞 문장, 짧으면 앞 문단 머리 140자)을 붙인다 |
| `SessionEnd` | 열린 항목(`- [ ]`)이 없으면 노트를 지운다 |

## 노트가 지워지는 때

폰·데스크톱 앱에서는 세션을 직접 끝낼 수 없어 `SessionEnd` 가 거의 오지 않고, 아카이브를 알리는 훅도 없다. 그래서 세 경로로 지운다.

| 경로 | 조건 |
|------|------|
| `핀 닫기` | 입력한 즉시 이 세션 노트 삭제 (아카이브 전에 치면 된다) |
| 방치 정리 | 아무 세션에서 메시지를 보낼 때, 대화가 멈춘 다른 세션 노트를 삭제 — 열린 항목이 없으면 **1일**, 있으면 **3일** |
| `SessionEnd` | 세션이 끝날 때 열린 항목이 없으면 삭제 |

대화가 멈췄는지는 세션 기록 파일(`~/.claude/projects/*/<session_id>.jsonl`)의 수정 시각으로 본다.
매핑이 기기마다 따로라 각 기기는 자기 기기에서 만든 노트만 지운다.

답이 된 질문을 `[x]` 로 바꿔 「끝남」 으로 옮기는 것과 「진행 중」 관리는 Claude 몫이다 (주입되는 컨텍스트가 지시한다).

노트: `<볼트>/00_Inbox/세션 핀/<YYYY-MM-DD HHMM> <첫 메시지 24자>.md`
세션 ID → 노트 경로 매핑: `~/.claude/session-pins/<session_id>.path`

## 설정

| 변수 | 의미 |
|------|------|
| `OBSIDIAN_VAULT` | 볼트 루트. 없으면 아무것도 하지 않는다 |
| `SESSION_PIN_DIR` | (선택) 노트 폴더를 직접 지정 — 시험용 |
| `SESSION_PIN_MAP` | (선택) 매핑 폴더 — 시험용 |
| `SESSION_PIN` | (선택) `0` 이면 끄고 `1` 이면 강제로 켠다 |

대화형 세션(Remote Control, 터미널 `cli`, 데스크톱 앱, VS Code)에서만 동작하고, `claude -p` 배치에서는 아무것도 하지 않는다.
Python 3.10+ 표준 라이브러리만 쓴다 (`python3` 이 없으면 `python` 으로 실행).

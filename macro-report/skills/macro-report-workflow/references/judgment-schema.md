# 판단 파일 형식 (v2)

`데이터/{날짜}/판단.md` 의 단일 출처. 판단 파일은 **LLM 용**이다 — 사람이 읽는 것은 쉬운말 보고서뿐이다.
판단 파일의 ```json 블록이 **예측 원장**이다. `scripts/weekly_score.py` 가 매주 모든 판단 파일을 훑어 만기가 된 예측을 채점하므로, 보고서를 게시한 뒤에는 판단 파일을 **고치지 않는다** (채점 대상이 바뀐다). 같은 실행 안에서 게시 전에 고치는 것은 괜찮다.

## 파일 구조

````markdown
---
생성일: YYYY-MM-DD
분석타입: 거시경제-판단
---
# 판단 (YYYY-MM-DD)

## 근거 요약
(데이터 파일 5개에서 판단에 쓴 사실만. 불릿, 각 불릿 끝에 [출처 id])

## 시장 내재 기대치와 다르게 본 부분
(FedWatch·선물이 가격에 넣은 것과 이번 판단이 다른 지점. 없으면 "없음")

## 예측 원장

```json
{ ... 아래 스키마 ... }
```
````

본문은 짧게 쓴다. 다음 주 판단이 이 파일을 입력으로 읽으므로 **근거 요약은 30줄 이내**.

## JSON 스키마

```json
{
  "version": 2,
  "report_date": "2026-10-05",
  "market_score": 47.5,
  "grade": "조건부 적합",
  "scenarios": [
    {"name": "기본", "prob": 0.55, "stance": 50, "summary": "한 문장"},
    {"name": "상방", "prob": 0.20, "stance": 80, "summary": "한 문장"},
    {"name": "하방", "prob": 0.25, "stance": 20, "summary": "한 문장"}
  ],
  "allocation": {"SPY": 25, "XLE": 5, "EWY": 5, "TLT": 10, "SHY": 40, "GLD": 15},
  "relative": [
    {"ticker": "XLK", "h1m": 0.55, "h3m": 0.60, "h6m": 0.55, "basis": [1, 4], "why": "한 줄"}
  ],
  "macro": [
    {"var": "DGS10", "h1m": "up", "h3m": "flat", "h6m": "down", "basis": [2], "why": "한 줄"}
  ],
  "fed": {"meeting": "2026-10-28", "market_hike_prob": 68.65, "our_hike_prob": 75, "basis": [3]},
  "risk_alarms": [
    {"indicator": "10년물 금리", "now": "4.62%", "line": "5.00%", "action": "주식 5%p 축소"}
  ],
  "sources": [
    {"id": 1, "publisher": "연합뉴스", "date": "2026-10-02", "title": "제목", "url": "https://..."}
  ]
}
```

### 필드 규칙

| 필드 | 규칙 |
|---|---|
| `market_score` · `grade` | `scoring-criteria.md` 의 종합 투자 적합도 (v2 가중치) |
| `scenarios` | 정확히 3개 (기본·상방·하방). `prob` 합 = 1. `stance` 는 그 시나리오의 위험자산 우호도 0~100 |
| `allocation` | 아래 **비중 가능 티커**만. 합계 100. 0 인 티커는 생략 |
| `relative` | 아래 **상대 성과 20개 전부**, 각 1회. `h1m/h3m/h6m` = 그 기간 뒤 **S&P 500(SPY) 보다 수익률이 높을 확률** (0~1) |
| `macro` | 아래 **거시 변수 11개 전부**. 방향은 `up` / `down` / `flat` (유지 폭 안의 변화 = flat) |
| `fed` | 다음 FOMC 1건. `market_hike_prob` 은 데이터 플랫폼 `/api/fed-expectations/latest` 값 그대로 (%) |
| `basis` | 모든 `relative` · `macro` 항목에 1개 이상. `sources` 의 `id` 만 |
| `sources` | 데이터 파일에 적힌 출처를 옮긴다. `url` 은 원문 링크 (데이터 플랫폼 수치면 FRED 시리즈 페이지 또는 API 경로) |

기간: `h1m` = 30일, `h3m` = 91일, `h6m` = 182일. 기준 가격은 **판단일 종가** (판단일이 휴장이면 직전 거래일).

### 비중 가능 티커 (24개)

- 자산군 4: `SPY` (미국 주식) · `TLT` (장기채) · `SHY` (단기채, 현금 대용) · `GLD` (금)
- 상대 성과 20: 아래 표

| 구분 | 티커 |
|---|---|
| 섹터 11 (GICS 전체) | XLK · XLF · XLV · XLE · XLY · XLP · XLI · XLB · XLU · XLRE · XLC |
| 반도체 · 소형주 | SMH · IWM |
| 지역 | EWY (한국) · EFA (선진국) · EEM (이머징) |
| 거시 민감 세부 업종 | XBI (바이오) · KRE (지역은행) · ITB (주택건설) · ITA (방산) |

개별 종목은 쓰지 않는다 (v1 에서 종목 추천은 S&P 500 대비 승률 약 50% — 동전던지기였다).

### 거시 변수 11개와 '유지(flat)' 폭

| `var` | 데이터 | 변화 기준 | flat 폭 |
|---|---|---|---|
| `FEDFUNDS` | 실효 연방기금금리 (월간) | 수준 차 | ±0.125%p |
| `DGS10` | 미 10년물 금리 | 수준 차 | ±0.10%p |
| `CPI` | 미 CPI 전년비 (월간) | 전년비의 차 | ±0.2%p |
| `SPY` | S&P 500 | 변화율 | ±2% |
| `WTI` | WTI 유가 | 변화율 | ±5% |
| `VIX` | VIX | 수준 차 | ±2pt |
| `USDKRW` | 원/달러 (`KRW=X`, 오르면 원화 약세) | 변화율 | ±1% |
| `KOSPI` | 코스피 | 변화율 | ±2% |
| `GOLD` | 금 선물 | 변화율 | ±3% |
| `HY_SPREAD` | 하이일드 스프레드 | 수준 차 | ±0.25%p |
| `UNRATE` | 미 실업률 (월간) | 수준 차 | ±0.1%p |

월간 지표(FEDFUNDS·CPI·UNRATE)는 채점 때 **그 시점에 발표돼 있던 최신값**으로 비교한다 (관측월 + 45일). 1개월 예측은 새 발표가 한 번 들어가는 정도라 flat 이 기본값에 가깝다.

## 확률을 쓰는 법

채점은 Brier 점수 `(확률 − 결과)²` 평균이다. 항상 0.5 를 쓰면 0.25 — 이보다 낮아야 예측에 의미가 있다.

- **근거가 없으면 0.5 에 가깝게.** 20개 전부 0.3/0.7 로 찍으면 틀릴 때 크게 잃는다
- 강한 확신도 **0.25 ~ 0.75** 를 넘지 않는 것이 보통이다. 넘기려면 근거 요약에 이유를 적는다
- 섹터 11개는 S&P 500 을 나눠 가진 것이므로 **전부 0.5 초과이거나 전부 미만일 수 없다** (시가총액 가중으로 대략 상쇄)
- 지난 판단과 확률을 크게(0.15 이상) 바꾼 항목은 `why` 에 무엇이 바뀌었는지 적는다
- **시장 내재 기대치와 다르게 볼 때만** 가치가 생긴다. FedWatch 확률과 같은 결론이면 그대로 따르고, 다르면 "시장 내재 기대치와 다르게 본 부분" 에 근거를 쓴다

## 검증

쓰고 나면 반드시 실행한다:

```bash
python3 "$P/scripts/weekly_score.py" validate "<판단.md 경로>"
```

`통과` 가 나올 때까지 고친다. 검증 실패한 판단 파일은 채점에서 빠진다.

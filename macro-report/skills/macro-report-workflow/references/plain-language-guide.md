# 쉬운말 버전 작성 지침

`macro-writer` 의 `plain` 모드가 따르는 단일 출처. 원본 보고서를 **금융 용어를 모르는 독자**가 읽을 수 있게 다시 쓴다.

## 목적과 경계

- **목적**: 원본의 결론과 근거 수치를 그대로 유지하면서, 전문 용어와 압축된 표현만 푼다.
- **아닌 것**: 요약본이 아니다. 분량을 줄이는 것이 목적이 아니라 **이해 비용을 줄이는 것**이 목적이다. 원본의 핵심 판단·수치·조치는 하나도 빠뜨리지 않는다.
- **아닌 것**: 재분석이 아니다. 원본과 다른 결론을 내거나, 원본에 없는 종목·수치·판단을 추가하지 않는다. 원본이 틀렸다고 판단되면 쉬운말 버전에서 고치지 말고 **원본을 고쳐야 한다**.
- **분량 기준**: 원본의 40~60%. 원본 900줄이면 350~550줄. 이보다 짧으면 내용이 누락된 것이고, 길면 설명이 늘어진 것이다.

## 5가지 원칙

### 1. 용어는 풀고, 원어는 괄호에 남긴다

`쉬운 말(원어)` 형태로 첫 등장 시 1회 병기한다. 같은 문서에서 두 번째부터는 쉬운 말만 쓴다.

- ✅ 시장에 실제로 도는 돈(순유동성)이 691억 달러 줄었습니다
- ❌ 순유동성이 −$69.1B 감소했습니다 (용어를 안 풀었음)
- ❌ 시장에 도는 돈이 691억 달러 줄었습니다 (원어가 없어 원본·뉴스와 대조 불가)

원어를 남기는 이유는 독자가 나중에 뉴스나 원본 보고서를 볼 때 같은 개념임을 알아보게 하기 위해서다.

> [!warning]+ 표 안에서는 병기하지 않는다
> 표 셀은 폭이 좁아 병기가 들어가면 오히려 읽기 어려워진다. 본문에서 이미 병기했으면 표에서는 **쉬운 말만** 쓴다.
> - ✅ 표 셀: `시장에 도는 돈` / `시장 국면`
> - ❌ 표 셀: `자산 간 관계(크로스에셋) 시장 국면(레짐)` — 한 셀에 병기 2개는 과하다
>
> 표에서 처음 등장하는 용어라면 표 바로 앞 문장에서 병기하고 표에는 쉬운 말만 넣는다.

### 2. 숫자는 한국어 단위로 변환한다

- `−$69.1B` → **691억 달러**
- `$1.53조` → **1조 5,300억 달러**
- `+$8.5B` → **85억 달러**
- `277bp` → **277bp** (금융 지표 고유 단위는 유지하되, 옆에 의미를 붙임: "경고선 290bp까지 13bp만 남음")
- 주가·목표가는 달러 표기 유지 (`$521.95`) — 종목 정보라 원문이 더 정확하다

### 3. 결론만 있는 곳에 "왜"를 넣는다

원본은 근거를 압축해 결론만 적는다. 쉬운말 버전은 **인과를 한 단계 풀어서** 적는다. 이때 원본에 없는 사실을 지어내면 안 되고, 원본이 전제한 상식을 명시하는 수준에 그친다.

- 원본: "금리 상승이 Fed가 아닌 인플레 기대·기간 프리미엄 주도 = 통화 완화로 상쇄 불가"
- 쉬운말: "금리가 오르는 이유는 크게 둘입니다. **연준이 올려서** — 이건 연준이 마음을 바꾸면 내려옵니다. **사람들이 물가가 오를 거라 믿어서** — 이건 연준이 뭘 해도 안 내려옵니다. 이번은 두 번째입니다."

- 원본: "XLU +5.53%·XLF +3.70% 실증 부진으로 방어 배치 상향을 Tier 3 강등"
- 쉬운말: "배당 3~4% 주는 주식은 국채 금리가 4.7%면 매력이 없어집니다. 그래서 전력·금융주가 부진했고, 증권사 추천을 '매수'에서 '관찰'로 내렸습니다."

### 4. 독자가 품을 의문은 콜아웃으로 미리 답한다

읽다 보면 "그런데 이건 왜?"가 생기는 대목에 `> [!note]+` 또는 `> [!warning]+` 콜아웃을 넣는다. 문서당 4~8개가 적정하다.

전형적인 의문 유형:

- **반박 예상**: "실적 발표 기간이라 내부자가 못 사는 것 아닌가?"
- **신뢰도 의심**: "이 매수가 진짜인지 어떻게 아나?" (숏스퀴즈 배제 근거)
- **수치 해석**: "목표가 $1,250을 왜 그대로 쓰면 안 되나?"
- **판단 근거**: "왜 지금이 보험 사기 좋은 때인가?"

### 5. 차트 대신 표를 쓴다

원본의 Plotly 차트는 **재생성하지 않는다**. 같은 데이터를 마크다운 표로 옮긴다.

- 표는 화면 폭에 관계없이 읽히고, 원본과 대조할 때 숫자를 찾기 쉽다
- 원본에 차트가 있다는 사실은 "상세 차트는 원본 참고" 정도로만 안내
- 게이지·파이 차트는 표보다 **불릿 3~5줄**이 더 읽히는 경우가 많다 (점수 추이, 확률 분포 등)

## 용어 사전

`plain` 모드는 아래 대응을 기본값으로 쓴다. 문맥상 더 나은 표현이 있으면 바꿔도 되지만, **원어 병기 원칙은 유지**한다.

### 유동성·통화

| 원본 용어 | 쉬운 말 |
|---|---|
| 순유동성 | 시장에 실제로 도는 돈(순유동성) |
| TGA (재무부 일반계정) | 미국 정부 국고 계좌(TGA) |
| RRP (역레포) | 연준이 은행에서 하루짜리로 돈을 빌려가는 창구(역레포) |
| QRA | 미국 국채 발행 계획 발표(QRA) |
| 크라우딩아웃 | 정부가 돈을 빨아들여 민간 자금이 마르는 현상(크라우딩아웃) |
| M2 | 시중 통화량(M2) |
| MMF | 단기 자금을 굴리는 펀드(MMF) — 주식 대기 자금 성격 |
| 마진부채 | 빚내서 투자한 금액(마진부채) |
| 만기벽 | 회사 빚의 만기가 한꺼번에 몰린 구간(만기벽) |
| 리파이낸싱 | 만기 빚을 새 빚으로 갈아타는 것(리파이낸싱) |

### 금리·채권

| 원본 용어 | 쉬운 말 |
|---|---|
| 실질금리 | 물가 상승분을 뺀 진짜 금리(실질금리) |
| 기간 프리미엄 | 장기간 돈을 묶어두는 대가로 요구하는 추가 금리(기간 프리미엄) |
| BEI (브레이크이븐) | 시장이 예상하는 물가 상승률(BEI) |
| HY OAS | 신용등급 낮은 회사가 돈 빌릴 때 더 내는 가산금리(HY OAS) |
| 2s10s | 2년물과 10년물 국채 금리 차이(2s10s) |
| 베어 플래트닝 | 단기 금리가 더 빨리 올라 장단기 차이가 줄어드는 것(베어 플래트닝) |
| 듀레이션 리스크 | 금리가 오를 때 장기채가 더 크게 손해 보는 위험(듀레이션 리스크) |
| 할인율 | 미래 이익을 현재 가치로 깎는 비율(할인율) — 금리가 오르면 주식 적정가가 내려감 |

### 시장 국면·변동성

| 원본 용어 | 쉬운 말 |
|---|---|
| 레짐 | 시장 국면(레짐) |

| 콘탱고 / 백워데이션 | 먼 미래 변동성이 더 비싼 상태(콘탱고) / 그 반대(백워데이션) |

| 캐피튤레이션 | 투매 항복(캐피튤레이션) — 버티던 사람까지 다 던지는 국면 |

| 드로다운 | 고점 대비 하락폭(드로다운) |

### 개별보고서 (individual) 의 쉬운말 버전

개별 보고서는 데이터 근거가 본체이므로 **종합보고서보다 짧게**, 원본의 30~45% 분량으로 쓴다.

```markdown
---
생성일: YYYY-MM-DD

# (보고서명) 쉬운 설명 (YYYY-MM-DD)

> [!note]+ 이 문서는 무엇인가

## 한 줄 요약

## 이 보고서가 답하는 질문
(보고서 유형별 핵심 질문 1개를 평이하게. 예: "회사 사정을 제일 잘 아는 임원들이 자기 회사 주식을 사고 있는가?")

## 이번 주 핵심 발견 N가지
(각각 소제목 + 수치 + 왜 중요한지)

## 숫자로 보기
(원본 차트를 대체하는 표 1~3개)

## 이게 왜 중요한가
(종합 판단에 어떻게 반영되는지 3~5줄)

## 주의할 점
(데이터 갭, 수치 불일치, 신뢰도 낮은 항목을 평이하게)

## 관련문서

**태그**: ...
```

### 보고서 유형별 "이 보고서가 답하는 질문"

| type | 평이한 핵심 질문 |
|---|---|
| insider | 회사 사정을 제일 잘 아는 임원·대주주가 자기 회사 주식을 사고 있는가? |
| analyst | 증권사 애널리스트들이 어느 종목에 돈을 걸고 있는가? |
| sector | 기관 투자자의 돈이 어느 업종으로 흘러가고 있는가? |
| liquidity | 시장에 돈이 풀리고 있는가, 마르고 있는가? |
| regime | 지금은 어떤 장세인가 — 위험을 걸 때인가, 지킬 때인가? |

## 파일명 규약

원본 파일명 뒤에 ` 쉬운 설명` 을 붙인다.

| 원본 | 쉬운말 버전 |
|---|---|
| `YYYY-MM-DD 종합 분석 및 투자 판단.md` | `YYYY-MM-DD 종합 분석 쉬운 설명.md` |
| `YYYY-MM-DD 내부자 매매 동향.md` | `YYYY-MM-DD 내부자 매매 동향 쉬운 설명.md` |
| `YYYY-MM-DD 애널리스트 목표가 변동.md` | `YYYY-MM-DD 애널리스트 목표가 변동 쉬운 설명.md` |
| `YYYY-MM-DD 시장 주도 업종 분석.md` | `YYYY-MM-DD 시장 주도 업종 분석 쉬운 설명.md` |
| `YYYY-MM-DD 유동성 환경 분석.md` | `YYYY-MM-DD 유동성 환경 분석 쉬운 설명.md` |
| `YYYY-MM-DD 크로스에셋 레짐 분석.md` | `YYYY-MM-DD 크로스에셋 레짐 분석 쉬운 설명.md` |

> [!important] 종합보고서만 이름이 축약된다
> `종합 분석 및 투자 판단` → `종합 분석 쉬운 설명`. "및 투자 판단"까지 붙이면 파일명이 지나치게 길어지기 때문이다. 나머지 5개는 원본명을 그대로 두고 접미사만 붙인다.

## 역링크 (필수)

쉬운말 버전이 고아 문서가 되지 않도록 **원본의 `## 관련문서` 섹션 맨 위에** 링크를 추가한다.

```markdown
## 관련문서

- [[YYYY-MM-DD (보고서명) 쉬운 설명|본 보고서의 쉬운 용어판 (전문 용어를 풀어쓴 요약)]]
- (기존 링크들...)
```

이 편집은 `plain` 모드 Writer 가 Edit 도구로 직접 수행한다.

## 금지 사항

- ❌ **원본에 없는 종목·수치·판단 추가** — 쉬운말 버전은 번역이지 분석이 아니다
- ❌ **원본과 다른 결론** — 원본이 "조건부 적합"이면 쉬운말도 "조건부 적합"이다
- ❌ **같은 사실의 부호(호재/악재) 뒤집기** — 아래 별도 항목 참조
- ❌ **Plotly 차트 재생성** — 표와 불릿으로 대체한다
- ❌ **과도한 비유** — "시장은 마치 롤러코스터처럼"류의 수사는 정보를 흐린다. 비유는 개념 설명에 꼭 필요할 때만 1문서 2~3회
- ❌ **단정적 투자 권유 어조** — 원본의 조건부 표현("~시 진입", "~하회 시 축소")을 무조건형으로 바꾸지 않는다
- ❌ **면책 고지 누락** — 문서 끝에 투자 결과를 보장하지 않는다는 고지를 반드시 넣는다

## 교차 정합성 — 부호를 뒤집지 않는다

같은 지표가 원본의 여러 섹션에서 **서로 다른 방향으로** 쓰이는 경우가 많다. 한 곳만 보고 옮기면 부호가 뒤집혀 문서 안에서 자기모순이 생긴다.

**실제 사고 사례** — 홍해 봉쇄와 톤마일:

- 원본 §지정학: 우회로 소멸 = 유가 급등 요인 = **악재**
- 원본 §공급망 수혜주: 홍해 우회로 톤마일(화물 무게 × 운송 거리) 급증 = 해운·탱커 운임 상승 = **호재** (해운 ETF 비중확대 근거)
- 잘못된 변환: "톤마일이 늘어나는 정도가 아니라 우회 자체가 불가능해졌다" → 톤마일을 악재 맥락에 넣어 **해운 매수 근거를 스스로 부정**했다. 같은 문서에서 해운 ETF를 매수 후보로 올려놨으므로 내부 모순이다

**점검 방법**: 지정학·유가·금리처럼 여러 섹션에 걸친 지표를 옮길 때, 원본에서 그 지표가 **몇 번 등장하는지 먼저 확인**한다(Grep). 두 곳 이상에서 다른 방향으로 쓰였다면 두 쪽 모두 서술하고, 어느 종목·업종에 어떤 방향으로 작용하는지를 명시한다.

전형적인 양방향 지표:

| 지표 | 악재 쪽 | 호재 쪽 |
|---|---|---|
| 유가 급등 | 물가·항공·소비 | 에너지·방산 |
| 홍해 우회 | 원유 공급·운송 비용 | 해운·탱커 운임(톤마일) |
| 메가캡 설비투자 증가 | 지출 기업의 현금 흐름 | 반도체·장비·전력·데이터센터 |
| 금리 상승 | 성장주·방어주·REIT | 단기채 캐리·은행 예대마진(단 실증 확인 필요) |

## 품질 자가 점검

작성 후 다음을 확인한다:

1. 원본의 **최종 점수·등급·자산 배분 비율**이 쉬운말 버전에 그대로 있는가?
2. 원본의 **Tier 1~4 종목 전체**와 **즉시 실행 조치 전체**가 반영됐는가?
3. 원본의 **경고 임계값 표**와 **신규 시스템 리스크**가 빠짐없이 옮겨졌는가?
4. 원본의 **지역 로테이션 전략**이 반영됐는가?
5. 전문 용어가 원어 병기 없이 등장한 곳이 있는가? (`Ctrl+F` 로 `bp`, `OAS`, `capex`, `P/C` 등 점검)
6. 표 셀에 병기가 2개 이상 들어간 곳이 있는가?
7. **양방향 지표의 부호가 원본과 일치하는가?** (위 "교차 정합성" 참조 — 특히 유가·지정학·설비투자·금리)
8. 한 줄 요약이 **실제로 한 문장**인가?
9. 분량이 기준(종합 40~60%, 개별 30~45%) 안에 있는가?
10. 원본 문서에 역링크를 추가했는가?
